# Required format

Dissertations are normally 40-80 pages long (in total). The actual length of a dissertation depends on the topic and whether it includes tables, graphs, equations, etc.

- Pages must be numbered.
- The thesis must be a single PDF formatted to A4 page size, and must be word processed (most common choices are Word or LaTeX). A LaTeX template is at the bottom of the Indicative Resource list
- Further details are provided on Indicative Resource list.

## Required components of the dissertation

- The first page should include the project title, your name, your student number and supervisor's name.
- The report must have an abstract of no more than 200 words.
- Any preface and acknowledgements should be listed on the second page.
- A list of references cited in the dissertation must be collected at the back.
- For tables, references etc, you should follow the style guidelines of any of the Journals of the Royal Statistical Society (look at any recent issue). Enumerate all tables and figures and refer to them in the text using their number.
- All figures and tables should have a caption explaining (but not interpreting) the content.
- Programming codes need to be provided electronically in a separate file.

## Dissertation submission

MSc dissertation pdf file together will all other supplementing files must be submitted electronically via Tabula. The additional files can be submitted in a zipped (compressed) folder. The file or folder should be named ST980_1234567, with the student university number (ID) instead of 1234567. All files need to be submitted as a group in one go, if the files are uploaded separately then the latest submitted file may overwrite the previously submitted ones.

Students are required to submit any additional files (work files, technical files, codes) that they used to produce their dissertation. No confidential data, standard libraries, precompiled binaries or very large data files should be included. It is good practice to also include a README file containing the instructions of how to use the submitted files to reproduce the results.

If any kind of a code has been used (e.g. R file, R Markdown file, raw code, python notebook), then it is mandatory to submit it together with the dissertation. The important part of the code to include is anything substantial developed in order to address the main questions of the dissertation. This might be novel code or scripts which make use of existing packages. It must be detailed enough to allow the markers to reproduce the results. The code should be clean and systematically laid out (for example, by using a pretty-printing utility), clearly annotated with explanatory comments, and no longer than required.
